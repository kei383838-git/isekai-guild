# レベル仕様

## 1. 基本方針

* プレイヤーは敵討伐で経験値を得る
* 累計経験値が必要量に達するとレベルアップする
* レベルは全ジョブ共通（docs/system/jobs.md §7）
* レベルダウンは存在しない（docs/world/lore.md §6）

## 2. 経験値の取得源

* 敵討伐時に、敵ごとに設定された XP を取得する
* クエスト達成・ダンジョン踏破による XP は現時点では対象外

### 敵ごとの XP（初心者の森）

| 敵                | XP |
|-------------------|----|
| slime             | 3  |
| horned_rabbit     | 5  |
| goblin            | 7  |
| mischievous_fairy | 10 |

XP 値は敵データ（リソース）に持たせる。
1 ダンジョンで敵 15〜20 体倒して累計 50〜100 XP、
初回プレイで Lv4〜5 到達を想定する。

## 4. レベルアップ時の上昇量（戦士）

| 項目     | Lv1  | 成長          | Lv20 | Lv99 |
|----------|------|---------------|------|------|
| HP_max   | 30   | +4/Lv         | 106  | 422  |
| SP_max   | 100  | +3/Lv         | 157  | 394  |
| attack   | 8    | +1/Lv         | 27   | 106  |
| defense  | 3    | +1/2Lv        | 12   | 52   |
| evasion  | 5%   | +0            | 5%   | 5%   |

* レベルアップ時は HP / SP を現在の max まで全回復する
* 回避率は戦士では伸ばさず、将来の斥候など他ジョブで差別化する
* defense は Lv 3, 5, 7, ..., 99 の奇数レベルのタイミングで +1 する

成長量もジョブごとに保持できる構造とし、初期は戦士の値を共用する。

## 5. ダメージ計算

詳細は [docs/system/combat.md](combat.md) §7 を参照。

```
回避判定: 1〜100 の乱数が受け手の evasion 未満なら回避（0 ダメージ）
命中時:   ダメージ = max(1, 攻撃側 attack - 受け手 defense)
```

* 最低 1 ダメージは保証する（不思議のダンジョン系の慣習）
* 敵は基本 defense = 0 / evasion = 0 とし、強敵は HP で調整する

## 6. 永続化

* `level`, `exp` は PlayerData Autoload に保持する
* HP / SP / attack / defense / evasion も最終的に PlayerData へ集約する想定
* セーブ・ロードは既存のスロット仕様（docs/system/save.md）に従う

## 7. UI

* レベルアップ時は LogManager にメッセージを流す
* レベルアップ時に短い画面演出を入れる（ColorRect フラッシュ等、画像不要）
* HP / EXP の HUD 常時表示は別途検討する

## 8. 一部ダンジョンのレベル1スタート

[docs/system/loot_loss.md](loot_loss.md) §6 を参照。
一部の高難易度ダンジョンではレベル1スタートし、終了時に元のレベルへ戻す。

仕組み：

* DungeonConfig に `level_reset` フラグを持つ
* 入場時にプレイヤーの level / experience を一時待避し、Lv1 / 0 EXP に置き換える
* 退出時（踏破・帰還・死亡）に待避した値へ復元する
* 中断セーブにも待避状態を含めるため、ダンジョン途中で中断・再開しても整合する

`level_reset = true` を付与するダンジョンは現時点では未定。
初心者の森（forest_beginner）は通常仕様（Lv 引継ぎ）のまま。
