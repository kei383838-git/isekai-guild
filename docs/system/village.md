# 拠点都市仕様

## 1. 基本方針

最初の拠点は、プレイヤーが探索前後に立ち寄る迷宮都市である。

現在は機能実装を急ぎ切る段階ではなく、
拠点の見た目、建物素材、背景素材、配置ルールを含む基盤整備を優先する。

迷宮都市は、迷宮を中心に発展した城壁都市として扱う。
四方を城壁に囲まれ、内部は整理された石畳の道と区画で構成される。

背景は、ギルド内部と同じく「1枚の背景画像 + 個別の建物/装飾Sprite2D」の方式を基本とする。
背景画像には都市の土台となる城壁、石畳、広場、区画、都市外周を描き、
主要施設の建物やイベント判定を持つ装飾は個別ノードとして配置する。

## 2. 現在の制作段階

- タイトル画面から拠点へ遷移できる
- 拠点からダンジョンへ入れる
- 拠点の主要施設の見た目を整備中である
- 64x64 タイル基準への移行を進めている
- 田舎町から迷宮都市へ背景方針を変更する

## 3. 拠点の主要施設

初期の拠点では以下の施設を配置する。

- 冒険者ギルド
- 鍛冶屋
- 薬屋
- 教会
- 商店
- 自宅

これらはすべてプレイヤーが入れる建物として扱う。

## 4. 建物サイズルール

- プレイヤーが入れる建物は 3x3 タイルとする
- 64x64 基準では 192x192 ピクセルを基本サイズとする
- 入口はプレイヤーサイズに対して違和感のない大きさを確保する
- 建物は明るい異世界ファンタジーの迷宮都市に合う雰囲気で制作する
- 背景画像には主要施設そのものを描き込まず、建物スプライトを置くための区画や敷地を用意する
- 入口セル、通行不可セル、イベント判定は背景画像だけに依存せず、個別ノードやグリッド管理で扱う

## 5. 将来の装飾建物

- 将来的に、入れない飾り用の家や背景建物を追加する可能性がある
- 飾り用建物は 2x2 タイルを許可する
- ただし、機能建物と混同しないよう役割を明確に分ける

## 6. 迷宮都市背景方針

- 拠点都市の屋外マップは、1枚の背景画像を基本にする
- 背景画像は 64x64 グリッドに合わせやすい寸法で制作する
- 画面内に全体を収める必要はないため、拠点背景の基準サイズは 2048x1536 とする
- 2048x1536 は 64x64 基準で 32x24 タイルに相当する
- 1280x960 は 20x15 タイルで、試作用としては使えるが、6つの主要施設、城壁、広場、整理された道を置くには余裕が少ない
- 背景には以下を含める
  - 四方を囲む城壁
  - 整理された石畳の道
  - 中央広場
  - 主要施設を配置できる開けた区画
  - 迷宮または迷宮区画へ続く開いた門や通路
  - 街灯、排水溝、植え込み、荷物置き場などの都市らしい土台表現
- 背景の密度方針
  - 建物を後置きしたときに、広すぎる石畳だけの空白が目立たないようにする
  - 街灯は主要な道や広場のアクセントに限定し、数を増やしすぎない
  - 建物の間や道沿いには、荷車、木箱、樽、掲示板、小さな屋台、ベンチ、植え込み、排水溝、石段などの低い装飾を配置する
  - 装飾は通行や建物配置を邪魔しない高さ・密度に抑える
  - 広場は完全な空白ではなく、通行可能な都市の生活感が出る程度に模様や小物を入れる
- 背景には以下を描き込みすぎない
  - 主要施設の建物本体
  - プレイヤーが入る建物の入口判定
  - 後から差し替えたい重要なイベントオブジェクト
  - 建物区画を囲う塀や高い縁取り
  - 閉じた門や、通行できないように見える門扉
- 建物周辺は、囲いで閉じた敷地ではなく、石畳の広場や開けた建物前スペースとして表現する
- 門はプレイヤーが都市外や迷宮方面へ移動できる導線に見えるよう、開いた状態で描く

## 7. 配置・通行判定方針

- 見た目の都市土台は背景画像で表現する
- 建物、看板、掲示板、街灯、荷車、噴水などは必要に応じて個別Sprite2Dとして配置する
- 通行不可判定は、ギルド内部と同様に `blocking_props` やグリッド座標で管理する
- 背景上の城壁、外周、建物敷地などは、見た目とは別に通行不可セルとして設定する
- 建物位置は、背景に描かれた敷地や石畳区画に合わせて手動調整する

## 8. 現時点の優先事項

- 迷宮都市背景の完成度を上げる
- 建物素材の規格を揃える
- 既存の6つの主要施設を迷宮都市の区画に再配置する
- 背景画像、建物、装飾、通行不可セルの責務を分ける
- その後に都市内部や施設機能の実装を進める
