# 村仕様

## 1. 基本方針

最初の村は、プレイヤーが探索前後に立ち寄る拠点である。

現在は機能実装を急ぎ切る段階ではなく、
村の見た目、建物素材、地形素材を含む基盤整備を優先する。

## 2. 現在の制作段階

- タイトル画面から村へ遷移できる
- 村からダンジョンへ入れる
- 村の主要施設の見た目を整備中である
- 64x64 タイル基準への移行を進めている

## 3. 村の主要施設

初期の村では以下の施設を配置する。

- 冒険者ギルド
- 鍛冶屋
- 薬屋
- 教会
- 商店
- 自宅

これらはすべてプレイヤーが入れる建物として扱う。

## 4. 建物サイズルール

- プレイヤーが入れる建物は 3x3 タイルとする
- 64x64 基準では 192x192 ピクセルを基本サイズとする
- 入口はプレイヤーサイズに対して違和感のない大きさを確保する
- 建物は村の明るい異世界ファンタジーの雰囲気に合わせて制作する

## 5. 将来の装飾建物

- 将来的に、入れない飾り用の家や背景建物を追加する可能性がある
- 飾り用建物は 2x2 タイルを許可する
- ただし、機能建物と混同しないよう役割を明確に分ける

## 6. 地形タイル方針

- 村の地形タイルセットは 64x64 タイルを前提とする
- 明るい草地、石畳、土道、水辺などを中心に構成する
- 黒い縁が強く見える仮素材は使わず、やわらかい境界表現を優先する

## 7. 現時点の優先事項

- 村の見た目の完成度を上げる
- 建物素材の規格を揃える
- タイルセットを村マップで自然に使える状態へ整える
- その後に村内部や施設機能の実装を進める
