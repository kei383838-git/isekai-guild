# セーブ仕様

## 1. 基本方針

- 不思議のダンジョン系の慣習に揃える
- スロット 3 個固定。スロット間のコピー / 移動はしない
- 各スロットは「通常セーブ」と「中断セーブ」を別領域で持てる
- 中断セーブは再開時に消える（save scum 防止）

## 2. スロット

- スロット 1 / 2 / 3 の 3 つ
- 各スロットは独立。コピー・移動・スロット変更はできない
- 物理ファイル：`user://save/slot{N}.json`（1 ファイルに通常 / 中断を入れる）

## 3. 2 種類のセーブ

### 通常セーブ
- 拠点（村など、`Player.in_village == true`）に居る間に作成
- ロードしても残る（複数回ロード可能）
- 同スロットで再作成すると上書きされる

### 中断セーブ
- ダンジョン内で **階段に到達した時** にのみ作成可能
  （ダンジョン途中での任意中断は不可。不思議のダンジョン系の慣習に揃える）
- 階段マスに乗ると「次の階へ進む / 中断する / やめる」のプロンプトが出る
- 「中断する」を選ぶと中断セーブを書き出してタイトル画面へ戻る
- 「やめる」を選んだ後は、階段マスから一度離れて戻るまでプロンプトは再表示しない
- ロードすると消える（一度しか復帰できない）
- 同じスロットの通常セーブには影響しない
- メニューには「中断」項目はない（仕様：階段でのみ）

スロット内に通常と中断が共存する場合、ロード時は **中断を優先** する。
中断ロード後は中断データのみ削除し、通常セーブは残る。

## 4. セーブされるデータ

### 通常セーブ
- メタ情報：セーブ日時 / シーンパス
- PlayerData：inventory / equipment
- QuestManager：gold / active_quest_id / quest_progress
- Player ステータス：hp / max_hp / sp / max_sp / hunger / max_hunger /
  attack_power / facing / in_village

### 中断セーブ（上記に追加）
- dungeon_config_id：どのダンジョンか
- current_floor：中断した階（復帰時は **+1 階** から開始する）

復帰時はダンジョン内部の状態（マップ / 敵 / アイテム / 階段位置 等）は
新規生成するため、上記以外は保存しない。プレイヤーの位置 / HP / SP /
満腹度などは 4 節の Player ステータスで保持される。

## 5. セーブのタイミング

### 通常セーブ
- 村到着時に **自動セーブ**
- 村でメニューの「セーブ」ボタンから **明示セーブ** も可能
- ダンジョンから帰還した直後・死亡から復帰した直後にも自動セーブ

### 中断セーブ
- ダンジョン内で階段に到達した時のみ作成可能（上記 3 節参照）
- 作成後は自動でタイトル画面へ戻る

## 6. ロードのタイミング

- タイトル画面 → スロット選択画面 → 各スロット
- 各スロット行は以下のいずれかの状態：
  - 空き：「新規ゲーム」を開始可能
  - 通常のみ：通常セーブから村へ復帰
  - 中断あり（通常もあるかもしれない）：中断セーブから復帰、中断は削除
- 中断ロード時は **中断時点の +1 階** からダンジョン再開する。
  最深部の階段で中断していた場合は復帰時に踏破帰還する。
- ロード成立時に SaveManager.current_slot に該当スロット番号が入り、
  以降の中断 / 通常セーブはそのスロットへ書き出される

## 7. 死亡時の挙動

- ダンジョン内死亡 → ロスト処理 → 村へ強制帰還 → 自動セーブ更新
- 中断セーブは死亡では作られない（中断と死亡は別フロー）

## 8. ストレージ形式

- JSON。`user://save/slot{N}.json`
- ルート構造：
  ```
  {
    "version": 1,
    "normal": { ... } | null,
    "suspend": { ... } | null
  }
  ```
- バージョン番号でマイグレーションを管理する

## 9. 制約 / 今後詰める項目

- スロット間のコピー機能は持たない（仕様）
- セーブ削除機能は将来追加
- プレイ時間表示は将来追加
- 複数キャラ（スロット内にキャラ切替）は今のところ想定なし
- ダンジョンの種類が増えた場合、`dungeon_config_id → DungeonConfig` の
  レジストリ化を行う
