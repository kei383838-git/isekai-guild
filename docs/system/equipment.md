# 装備仕様

## 1. 基本方針

プレイヤーは持ち物の中から装備品を選んで装備する。
装備中のアイテムも持ち物リストには **残り続ける**。
（不思議のダンジョン系の慣習に揃える。リスト上では「(装備中)」表記で識別する）

## 2. 装備スロット

プレイヤーは以下 4 スロットに 1 個ずつ装備可能。

| スロット | 種別 (Item.Kind) | 用途 |
|---|---|---|
| 武器 (weapon) | WEAPON | 通常攻撃の威力に影響（Phase 3 以降） |
| 盾 (shield) | SHIELD | 被ダメージの軽減に影響（Phase 3 以降） |
| アクセサリー (accessory) | ACCESSORY | 状態異常耐性・特殊効果など |
| 投擲 (throw) | THROW | 投擲攻撃のベース。投擲アイテムを設定 |

各アイテムは「種別 (kind)」によって入るスロットが決まる。

## 3. 装備中の操作制約

装備中アイテムに対して許可される操作は **「外す」のみ**。

使う・捨てる・投げる は **装備を外してから** 行う。

これは在庫個数とスロット参照のずれを防ぐためのルールである
（同じ種類の剣を複数本持っている場合でも、シンプルに装備中扱いとする）。

## 4. ターン消費

ダンジョン内：装備 / 外す / 使う / 投げる / 捨てる は **1 ターン消費** する。
拠点（村など、`Player.in_village` が true）：消費なし。

これは [combat.md](combat.md) の「アイテム使用は 1 ターン消費」方針に揃える。

## 5. ロスト時の扱い

装備中アイテムも持ち物に残るため、所持品ロストの対象になり得る。
難易度別の挙動は [loot_loss.md](loot_loss.md) を参照。

ロスト等で在庫個数が 0 になった場合、対応スロットは自動で空になる
（`PlayerData.remove_item()` 側で処理）。

## 6. 戦闘効果（Phase 3 実装済み）

装備品は `stats` を持ち、装備中のスロット全てから合算された値が
プレイヤーの実効ステータスに加算される。

### 6.1 実効値の式

```
実効攻撃  = base_attack  + Σ(装備.stats.attack  + 強化値 if stats.attack 存在)
実効防御  = base_defense + Σ(装備.stats.defense + 強化値 if stats.defense 存在)
実効回避  = base_evasion + Σ(装備.stats.evasion + 強化値 if stats.evasion 存在)
```

`base_*` はレベルから算出されるベース値（[leveling.md](leveling.md) §4）。
装備補正の合算は `PlayerData.equipment_bonus(stat_name)` が担当する。

ダメージ計算式は [combat.md](combat.md) §7.1 を参照（風来のシレン式の割合軽減）。

### 6.1.1 強化値（+N）

各アイテムスタックに強化値 `enhance` が紐づく（[inventory.md](inventory.md) §1）。

- 「主 stat」= 装備の `stats` の最初のキー（武器=attack, 盾=defense, 等）
- 強化値は主 stat に対してそのまま加算される（例：+5 の木の剣 → 攻撃寄与 +8）
- 主 stat が無い装備（お守りなど）は強化対象外
- 装備を外しても **+N は失われない**（スタックが inventory に残り続けるため）
- 強化値の操作はデバッグメニュー（F11）から行う。詳細は [debug.md](debug.md) §3.2

強化素材・成功判定・強化メニュー UI は **Phase 4b** で実装予定。それまでデバッグ操作以外で
強化値は変動しない。

### 6.2 装備品の補正値（Phase 3 時点）

| キー | 種別 | 補正 | 備考 |
|---|---|---|---|
| wooden_sword | 武器 | 攻撃 +3 | 序盤武器 |
| wooden_shield | 盾 | 防御 +2 | 序盤盾 |
| talisman | アクセサリー | （補正値なし） | 効果は Phase 4 で [loot_loss.md](loot_loss.md) §8 のロスト 1 回防止を実装 |
| throw_stone | 投擲 | throw_power 4 | 投擲攻撃のダメージ源（Phase 4 で攻撃挙動を実装） |
| power_ring（力の指輪） | アクセサリー | 攻撃 +2 | |
| guard_ring（守りの指輪） | アクセサリー | 防御 +2 | |
| swift_ring（素早さの指輪） | アクセサリー | 回避 +5 | |

補正値の規模は「序盤は小（+2〜+5 程度）」を原則とする。
エンドコンテンツ用装備で上限を増やす想定（Phase 5 以降）。

### 6.3 数値バランスについて

ダメージ計算式を引き算からシレン式（割合軽減）へ切り替えたため、
既存敵 ATK との組み合わせは実機で調整する余地がある。

数値は実装と調整を繰り返して詰める前提とし、本仕様は方針の正本とする。
