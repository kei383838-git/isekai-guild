# 設定仕様

## 1. 基本方針

- ユーザー単位のゲーム設定。セーブデータとは独立して管理する。
- 物理ファイル：`user://settings.cfg`（Godot 標準 ConfigFile 形式）
- 起動時に読み込んで自動適用。変更時に即保存・即適用。
- メニューの「設定」項目から編集可能。

## 2. 設定項目（Phase 1）

| 項目 | デフォルト | 効果 |
|---|---|---|
| 操作ヘルプを表示する | ON | 画面右上の `KeyHelpOverlay` の表示切替 |
| 全画面表示 | OFF | ウィンドウ ⇔ フルスクリーン |
| 村到着時に自動セーブする | ON | `Village._ready` の通常セーブを実行するか |

## 3. UI

- PauseMenu → 「設定」項目で右側に設定パネルを表示
- 各項目は CheckBox。切り替えると即時保存・即時適用
- 設定を変更するためにメニューを閉じる必要はない

## 4. 永続化

ConfigFile セクション・キー：

```
[display]
show_help = true
fullscreen = false

[save]
auto_save = true
```

- ファイル未存在 / キー欠落の場合はデフォルト値を使う
- 値の保存・適用は `SettingsManager` (Autoload) が担当する

## 5. 既知の制約

- **エディタの埋め込みゲームウィンドウでは全画面切替が無効化される**
  Godot 4 の機能で、ゲーム実行ウィンドウをエディタ内に埋め込む設定
  （Game タブ → 歯車 → Embed Game）になっていると、
  `Embedded window only supports Windowed mode.` の警告が出て
  フルスクリーンに切り替わらない。エクスポートビルドでは正常に動く。
  エディタで動作確認したい場合は Embed Game をオフにする。
