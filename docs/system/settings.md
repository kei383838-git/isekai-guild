# 設定仕様

## 1. 基本方針

- ユーザー単位のゲーム設定。セーブデータとは独立して管理する。
- 物理ファイル：`user://settings.cfg`（Godot 標準 ConfigFile 形式）
- 起動時に読み込んで自動適用。変更時に即保存・即適用。
- メニューの「設定」項目から編集可能。

## 2. 設定項目（Phase 1）

| 項目 | デフォルト | 効果 |
|---|---|---|
| 操作ヘルプを表示する | ON | 画面右上の `KeyHelpOverlay` の表示切替 |
| 全画面表示 | OFF | ウィンドウ ⇔ フルスクリーン |
| 村到着時に自動セーブする | ON | `Village._ready` の通常セーブを実行するか |

## 3. UI

- PauseMenu → 「設定」項目で右側に設定パネルを表示
- 各項目は CheckBox。切り替えると即時保存・即時適用
- 設定を変更するためにメニューを閉じる必要はない

## 4. 永続化

ConfigFile セクション・キー：

```
[display]
show_help = true
fullscreen = false

[save]
auto_save = true

[bindings]
wait_kb   = 4194306   ; KEY_TAB（カスタムされた時だけ書かれる）
wait_pad  = 1         ; JOY_BUTTON_B
...
```

- ファイル未存在 / キー欠落の場合はデフォルト値を使う
- 値の保存・適用は `SettingsManager` (Autoload) が担当する
- `[bindings]` には **ユーザーがカスタムした分のみ** 書かれる。
  未カスタムの action はコード側のデフォルト (`ACTION_REGISTRY`) を使う

## 5. キーバインド (Phase 3)

メニューの「キー設定」項目から各アクションのキー / ゲームパッドを
再割当できる。

### リバインド対象

ゲーム中メニューの「キー設定」から再割当できるアクション：

| Action | 表示名 | キー (rebindable) | パッド (rebindable) |
|---|---|---|---|
| wait | 待機 | ✓ | ✓ |
| dash | ダッシュ | ✓ | ✓ |
| turn | 振り向き | ✓ | ✓ |
| attack | 攻撃 | ✓ | ✓ |
| diagonal | 斜め移動 | ✓ | ✓ (ボタン / LT・RT トリガー) |
| toggle_map | マップ | ✓ | ✓ |
| menu_toggle | メニュー | ✓ | ✓ |
| interact | 調べる | ✓ | ✓ |

`slot_delete` (Delete / Y) はタイトル画面の SlotSelect 専用のため、
ゲーム中メニューの一覧からは除外している（`in_game: false`）。

### リバインド操作

- キー設定画面で各行のキー or パッドボタンを Enter / A で押すと
  「操作を割り当てる」キャプチャモードに入る
- 次に押した入力（キー / ゲームパッドボタン / LT・RT トリガー）が割当られる
- Esc でキャンセル
- 「デフォルトに戻す」で全カスタムバインドを破棄しコードデフォルトに戻る

### 競合解消

同じキー / ボタン / 軸が別のアクションに既に割当てられている状態で
リバインドすると、**元の割当を自動で外す**（重複を防ぐ）。

外されたアクションには「明示的に空」マーカー (`-1` / `{"type":"none"}`)
が書かれ、次回起動時に default が復活しないようにする。
「デフォルトに戻す」で全アクションが default に戻る。

### 保存形式（[bindings] 内）

```
wait_kb       = 4194306                                  ; キーコード int
wait_pad      = {"type": "btn", "index": 1}              ; ボタン
diagonal_pad  = {"type": "axis", "index": 5, "value": 0.5}  ; LT/RT 等の軸
```

- ボタンと軸を 1 つの action 内で混在させない（差し替え時はもう片方が消える）
- 旧バージョン（int 形式の `_pad`）も読み込み互換あり

## 6. 既知の制約

- **エディタの埋め込みゲームウィンドウでは全画面切替が無効化される**
  Godot 4 の機能で、ゲーム実行ウィンドウをエディタ内に埋め込む設定
  （Game タブ → 歯車 → Embed Game）になっていると、
  `Embedded window only supports Windowed mode.` の警告が出て
  フルスクリーンに切り替わらない。エクスポートビルドでは正常に動く。
  エディタで動作確認したい場合は Embed Game をオフにする。
