# デバッグメニュー仕様

## 1. 基本方針

開発・テスト用途のための統合デバッグメニュー。
リリースビルドでも開けるが、UI 上に「デバッグ」と明示し、誤操作を防ぐ。

## 2. 起動

- **F11** キーでオーバーレイ表示・非表示をトグル
- 既存の **F12**（モンスター閲覧ギャラリー、`scripts/systems/DebugInput.gd`）とは独立
- 全シーン共通（Autoload `DebugMenu` 経由）

## 3. 機能

### 3.1 アイテム付与

`Item.DEFS` の全キーから 1 種を選択し、個数指定で `PlayerData.add_item()` を呼ぶ。
未鑑定アイテムが導入された後は識別状態の制御もここで行う想定（Phase 4 以降）。

### 3.2 装備強化（+N）

装備中スロットの **スタックの強化値** を直接書き換える。
詳細仕様は [equipment.md](equipment.md) §6.1.1 / [inventory.md](inventory.md) 参照。

- 上限なし（デバッグ用）
- 強化値はアイテムスタックに紐づくため、外しても保持される
- 効果：装備の主 stat（`stats` の最初のキー）に強化値が加算される
  - 例：+5 の木の剣（base attack +3）→ 攻撃寄与は +8
  - 主 stat が無い装備（お守りなど）は強化対象外（操作不可）
- 未装備スタックの +N を編集する UI は Phase 4b で検討

### 3.3 ゴールド付与

100 / 1000 ボタンで `QuestManager.gold` を増減する。

### 3.4 HP / SP / 満腹度

全回復ボタンでプレイヤーの hp / sp / hunger を上限まで一括回復する。

## 4. Phase 4 で正規実装される項目との関係

| 項目 | デバッグメニュー | 正規仕様 |
|---|---|---|
| 装備強化 +N | 直接書き換え | 強化素材を「使う」で対象選択（[equipment.md §6.1.2](equipment.md#612-強化素材phase-4b-実装済み)）／鍛冶屋 NPC は別途実装予定 |
| アイテム付与 | 任意の量を即時付与 | ダンジョン拾得 / ショップ購入 |
| ゴールド付与 | 直接加算 | 売却・クエスト報酬 |
| HP / SP / 満腹度 | 全回復 | 食料・休息・回復アイテム |

正規仕様の実装後もデバッグ用途として残す。

## 5. 注意事項

- 強化値はアイテムスタックに紐づくため、外しても保持される（[inventory.md](inventory.md) §4）
- アイテム付与時、stackable kind かつ enhance 一致のスタックがあればマージされる
  ([inventory.md](inventory.md) §2)。武器・盾・アクセは付与のたびに別個体として追加
- 操作は全てログに記録されない（テスト用なので静音）
