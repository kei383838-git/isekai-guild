# HUD 仕様

ゲーム画面上に常時表示する UI（HUD）の方針をまとめる。
シーンは `scenes/ui/HUD.tscn`、スクリプトは `scripts/ui/HUD.gd`。

参考デザインは「不思議の幻想郷」の画面表示（`work/不思議の幻想郷参考資料/` 参照）。

## レイアウト概要

| 領域 | 内容 |
|---|---|
| 左上 | HP / SP / Hunger / 所持品 / ゴールド / 依頼進捗 / Lv・EXP |
| 画面下端 中央 | メッセージウィンドウ（行動ログ） |

## メッセージウィンドウ

### 位置・サイズ

- 画面下端中央、左右余白 32px
- 高さ 120px（5〜6 行分）
- 1280×720 ビューポートでの基準値であり、解像度変更時はアンカーで追従する

### 見た目

- 背景：黒の半透明 `Color(0, 0, 0, 0.72)`
- 枠：金色系 `Color("c9a357")` の細枠（上下 2px / 左右 1px）。
  将来 `NinePatchRect` の装飾枠絵に差し替える前提で、現状は `StyleBoxFlat` の仮置き
- パディング：内側 12px
- フォントサイズ：14

### 挙動

- `RichTextLabel` を使用、`bbcode_enabled = true`
- 新着ログで最下行まで自動スクロール（`scroll_following = true`）
- 行数上限 200。超過分は **先頭から削除** する
  （`get_line_count()` で測り、HUD.gd 側で間引く）
- **アイドル非表示**：最後の新着から 5 秒経過でフェードアウト（0.5 秒）して非表示。
  新着が来れば即時表示に戻る。起動直後（ログ未発生時）も非表示
- ログ自体は内部に保持されるため、再表示時は過去ログがそのまま見える

### ログ配色ルール

BBCode `[color=...]` で数値・キーワードを強調する。
基調は白で、以下のみ色付けする。

| 種別 | 色 | 例 |
|---|---|---|
| ダメージ数値 | `#ff8a6b`（赤系） | `[color=#ff8a6b]5[/color] ダメージを受けた！` |
| 経験値 / Lv 数値 | `#7fd3ff`（シアン系） | `経験値 [color=#7fd3ff]12[/color] を得た。` |
| レベルアップ全体 | `#ffd86b`（金色） | `[color=#ffd86b]レベル 5 になった！[/color]` |
| ゴールド | `#ffd86b`（金色） | `[color=#ffd86b]100 G[/color] を獲得した。` |
| アイテム名 | 現状は白のまま（将来検討） | |

## 戦闘ログの整合

プレイヤー被ダメージのログは `Player.gd` の `receive_attack()` 内で出す
（`take_damage()` 内では出さない）。

`take_damage()` は空腹ダメージ等、別文脈の呼び出し元もあるため、
内部で固定文言を出すと重複が発生する。空腹ダメージのログは
呼び出し元（`move()`）に残す。

Enemy 側 (`Enemy.gd`) と文体を対称にする：

| 状況 | Enemy 側 | Player 側 |
|---|---|---|
| 被ダメージ | `敵に N ダメージ！` | `N ダメージを受けた！` |
| 回避 | `敵に回避された！` | `攻撃を回避した！`（既存） |
| 撃破 | `敵を倒した！` | `やられた…`（Dungeon.gd 側） |

## 拡張余地

- 装飾枠の差し替え：`Panel` の `StyleBoxFlat` を `NinePatchRect` ベースに置換可能
- ログ送り：参考画像のように複数行をページ送りにする UI（A ボタンで送り）は将来検討
- アイテム名の配色：レア度別に色を分ける案は装備システム実装後
