# 異世界の不思議な冒険ギルド - ドキュメント

この docs フォルダは、本プロジェクトの仕様・世界観・用語の正本です。

## 運用方針
- 仕様を決めたら最初に docs を更新する
- 他チャットで相談するときは docs の内容を前提にする
- rules.md を最優先ルールとする
- 実装状況に関する確定事項も docs に反映する

## ファイル構成
- rules.md: 絶対にぶらさない前提ルール
- world/lore.md: 世界観の概要
- world/terminology.md: 用語定義
- system/core_loop.md: ゲームの基本進行
- system/village.md: 村と素材制作の確定仕様
- system/asset_structure.md: アセットディレクトリの配置ルール

## 現在の制作状況
- 現在は基礎機能の実装と並行して、最初の村の作り込みを進めている
- グラフィック基準は 64x64 タイルへ移行中である
- 村の機能建物は、プレイヤーが入れる 3x3 建物として整備する
- 村の地形タイルセットと建物素材は、明るいなろう系異世界ファンタジーの雰囲気で制作する
